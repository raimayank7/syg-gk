Computers and the internet: GK questions and answers

Computers are part of every school and office now. These questions cover the parts of a computer, the units of memory and the common terms of the internet.

Test yourself

Ten questions picked at random from this topic, four choices each. Or go through every question as flash cards.

20 questions on computers and the internet

  1. Which part is called the brain of the computer? CPU CPU stands for Central Processing Unit.
  2. Which of these is an input device? Keyboard A mouse, a scanner and a microphone are input devices too.
  3. Which of these is an output device? Printer A monitor and speakers are output devices too.
  4. How many bits make one byte? 8 A bit is a single 0 or 1.
  5. How many bytes are there in one kilobyte (KB)? 1,024 1,024 is 2 multiplied by itself ten times.
  6. Which number system do computers use internally? Binary Binary uses only two digits, 0 and 1.
  7. What does RAM stand for? Random Access Memory RAM loses its contents when the power is switched off.
  8. What does ROM stand for? Read Only Memory ROM keeps its contents even when the power is off.
  9. What does WWW stand for? World Wide Web The Web is one service that runs on the Internet. The two are not the same thing.
  10. What does URL stand for? Uniform Resource Locator A URL is the address of a web page.
  11. Which language is used to make web pages? HTML HTML stands for HyperText Markup Language.
  12. What does "e" in email stand for? Electronic Every email address has the sign @ in it.
  13. Which keys are used to copy selected text on Windows? Ctrl + C Ctrl + V pastes, Ctrl + X cuts and Ctrl + Z undoes.
  14. Which keys are used to paste on Windows? Ctrl + V On a Mac, the Command key is used in place of Ctrl.
  15. Which of these is an operating system? Windows Linux, macOS and Android are also operating systems.
  16. What do we call a harmful program that spreads from one computer to another? Virus Antivirus software finds and removes such programs.
  17. Which program is used to open websites? Web browser Chrome, Firefox, Edge and Safari are web browsers.
  18. Who is known as the first computer programmer? Ada Lovelace In the 1840s she wrote notes on how Charles Babbage's Analytical Engine could be given instructions.
  19. What does PDF stand for? Portable Document Format A PDF file looks the same on every device.
  20. What does USB stand for? Universal Serial Bus Pen drives, keyboards and phone chargers use USB.

These are well-established facts, written in our own words and last checked on 11 November 2026. If your textbook says something different, follow your textbook and tell us.
